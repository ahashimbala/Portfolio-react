## Getting Started

Before running the project locally, ensure you have the following installed:
Node.js: `v22.0.0` or higher (tested on `v22.20.0`) – [Download Node.js](https://nodejs.org/)
npm (v9.0.0 or higher, usually comes bundled with Node.js) or yarn/pnpm
Git– [Download Git](https://git-scm.com/)

Verify your installations by running:

bash
node -v
npm -v

## Follow these steps to setup and run the project locally

Clone the repository - git clone https://github.com/ahashimbala/Portfolio-react.git
cd Portfolio-react

## Install all required package dependencies

npm install

## Run the local development server with hot reload enabled

npm run dev

Once started, open your browser and navigate to http://localhost:5173 (or the local URL shown in your terminal).

## Useful Commands

npm run dev - Starts the Vite development server
npm run build - Bundles the application for productio (dist/ folder)
npm run preview - Serves the production build locally for testing
npm run lint - Runs ESLint to check for code formatting and style issues
